# Security Policy

## Supported versions

The project is under active development. Only the latest commit on `main` is supported.

## Reporting a vulnerability

Do not open a public issue for security problems. Report privately by email to
[hei.tiavina.1@gmail.com](mailto:hei.tiavina.1@gmail.com).

Please include:

- the affected component and file(s),
- a minimal reproduction,
- the impact you observed,
- any suggested remediation.

Reports are acknowledged within 72 hours, and fixes are prioritized over feature work.

## Scope

This project governs execution environments: default-deny, least privilege and
"verification over trust" are engineering principles here, not options. Issues related to
secret handling, command execution safety, permission escalation and audit integrity are
treated with the highest priority.
